3D Printing & Slicing Guide

This model is engineered specifically for support-free FDM 3D printing on beds like the Bambu Lab A1 Mini (180 × 180 mm).

1. With Bambu Lab AMS (Dual Material)

  • Select Dual Material mode and click Export STL.
  • Drag both color.stl and white.stl into Bambu Studio simultaneously.
  • Select Yes when asked: "Load these files as a single object with multiple parts?".
  • Assign Filament 1 (Orange) to plate/name and Filament 2 (White) to designation. Print flat with 0 supports!

2. Without AMS: Single Print Layer-Pause (1 Swap)

  • Select Layer Pause mode and download nameplate_layer_pause.stl.
  • In Bambu Studio / OrcaSlicer, slice the model at 0.2 mm layer height.
  • In the preview slider, scroll to layer height 3.2 mm (right after 3.0mm base plate).
  • Right-click the vertical layer slider and select Add Pause (M600).
  • The printer will automatically pause, allowing you to manually swap to White filament!

3. Without AMS: Inlay Snap-Fit Assembly (0 Swaps)

  • Select Inlay Assembly mode to print two completely separate parts.
  • Print base_inlay_recessed.stl in Orange.
  • Print designation_insert.stl in White.
  • Both print 100% single-color with 0 filament changes. Snap or glue the mating tab into the base socket!
